# 🤖 Telegram-бот со встроенным ИИ (Groq / OpenAI / Gemini)

Полнофункциональный умный Telegram-бот на Python с поддержкой ультра-быстрых языковых моделей **Groq** (`llama-3.3-70b-versatile`), **OpenAI** (`gpt-4o-mini` / `gpt-4o`) и **Google Gemini**, памятью диалога и расширенными командами.

---

## ✨ Возможности

- 🧠 **Ответы на любые вопросы**: От генерации идей и написания кода до решения задач и диалога на любые темы.
- ⚡ **Поддержка Groq API**: Ультра-высокая скорость ответа на современных моделях Llama 3.3 70B.
- 💬 **Память контекста**: Бот помнит историю сообщений в рамках диалога и умеет отвечать на уточняющие вопросы.
- 🛠️ **Команды бота**:
  - `/start` — Запуск и приветствие.
  - `/help` — Справка и возможности.
  - `/clear` — Очистить историю диалога и начать сначала.
  - `/info` — Информация о провайдере и используемой нейросети.
- 🚀 **Надёжность**:
  - Анимированный статус «печатает...» при генерации ответа.
  - Автоматическая разбивка длинных ответов (>4000 символов).
  - Безопасная обработка форматов разметки Markdown / Plain Text.

## 🚀 Быстрый старт и установка

### 1. Клонирование / Переход в папку проекта

```bash
cd agitated-heisenberg
```

### 2. Создание виртуального окружения (Venv)

```bash
python3 -m venv venv
source venv/bin/activate  # Для macOS / Linux
# venv\Scripts\activate   # Для Windows
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

## 🔑 Настройка ключей доступа (.env)

1. Скопируйте шаблон файла конфигурации:

```bash
cp .env.example .env
```

2. Откройте `.env` в текстовом редакторе и заполните необходимые данные:

### Шаг А: Токен Telegram-бота
- Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather).
- Напишите команду `/newbot` и следуйте подсказкам.
- Скопируйте полученный **HTTP API Token** и вставьте его в `.env`:
  ```env
  BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyZ
  ```

### Шаг Б: Подключение Groq API Key
1. Зарегистрируйтесь и получите бесплатный API-ключ в [Groq Console](https://console.groq.com/keys).
2. Укажите ключ в `.env`:
   ```env
   AI_PROVIDER=groq
   GROQ_API_KEY=gsk_...
   GROQ_MODEL=llama-3.3-70b-versatile
   ```

*(Также поддерживаются `AI_PROVIDER=openai` и `AI_PROVIDER=gemini`)*

## 🏃 Запуск бота

После настройки файла `.env` запустите бота командой:

```bash
python3 main.py
```

Откройте созданного бота в Telegram и напишите ему сообщение!
